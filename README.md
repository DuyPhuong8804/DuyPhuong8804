## Featured projects

### [YOLO Traffic Flow Analytics](https://github.com/DuyPhuong8804/YOLO-Traffic-Flow-Analytics) — Computer Vision

AI-powered traffic analytics system for detecting, tracking, classifying, and counting vehicles from video streams.

- Fine-tuned **YOLO** for vehicle detection, achieving **92.81% mAP@50** on the test dataset.
- Integrated object tracking and line-crossing algorithms for automated vehicle counting.
- Developed backend APIs and interactive visualization components using **FastAPI and Streamlit**.
- Used SQLite for structured data storage.

`Python` `YOLO` `OpenCV` `FastAPI` `Streamlit` `SQLite`

### [Production RAG Pipeline](https://github.com/DuyPhuong8804/K4-Track3A-DAY18-BuiPhuongDuy-2A202602684-ProductionRAG) — LLM & RAG

Document question-answering pipeline focused on improving retrieval quality and evaluating generated responses.

- Combined **BM25 and dense vector retrieval** using Reciprocal Rank Fusion (RRF).
- Implemented **reranking** to improve document retrieval relevance.
- Integrated **Qdrant** for vector storage and semantic search.
- Evaluated RAG performance using **RAGAS metrics** on a 20-question evaluation dataset.

`Python` `Qdrant` `Sentence Transformers` `BM25` `RRF` `RAGAS`

### [Multi-Agent MCP + A2A](https://github.com/DuyPhuong8804/K4-L3B-MultiAgent-MCP-A2A) — Agentic AI

Deterministic multi-agent workflow for investigating e-commerce customer complaints using structured evidence.

- Developed a coordinator-driven architecture with specialized agents.
- Integrated **Model Context Protocol (MCP)** tools for structured evidence retrieval.
- Implemented evidence tracking and access-control mechanisms.
- Designed verification and conflict-resolution workflows to improve decision reliability.

`Python` `AsyncIO` `MCP` `Multi-Agent Systems` `Agent Workflows`

### [Hybrid Recommendation System](https://github.com/DuyPhuong8804/recommender-system) — Machine Learning

Fashion product recommendation application combining content-based and collaborative filtering methods.

- Developed content-based recommendations using **TF-IDF and cosine similarity**.
- Implemented **KNN-based collaborative filtering**.
- Built an interactive recommendation interface with **Streamlit**.
- Combined multiple recommendation techniques to provide personalized product suggestions.

`Python` `Scikit-learn` `KNN` `TF-IDF` `Streamlit`
